# Shad Jewel brand assets

Source: full logo PNG (icon + “Shad Jewel” wordmark on black), 960×960 RGBA.

| File | Use |
| --- | --- |
| `logo-full-black.png` | Original master (black background) |
| `logo-full-transparent.png` | Transparent cutout of the full mark |
| `logo-light-transparent.{png,webp}` | Full mark for **light** surfaces (header/footer/OG/watermark) — outlines darkened for contrast |
| `logo-dark-transparent.{png,webp}` | Full mark for **dark** surfaces |
| `logo-nav.png` / `logo-nav-dark.png` | Nav-height masters |
| `mark-flower-transparent.{png,webp}` | **Flower icon only** (no wordmark) — favicons / app icons / footer chip |
| `og-image.png` | Open Graph share card source |

Favicons / PWA icons under `public/` and `src/app/` are derived from the flower mark only.
